## 这是什么

weber-code-agent 是一个代码智能体：理解代码、执行任务，协助完成软件开发工作。

它想验证的是同一件事在不同尺度上的表现——单个仓库里的改动、跨仓库的检索与重构，以及把「改代码」这件事交出去之后，人还剩下哪些必须亲自做的判断。
