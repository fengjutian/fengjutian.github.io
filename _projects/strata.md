## 这是什么

Strata 是一个面向团队的开源项目管理平台，将工作项、周期、模块、视图、页面和数据分析放进同一个工作空间。

它既支持云端使用，也支持通过 Docker Compose 或 Kubernetes 私有化部署。

## 技术栈

- **TypeScript、React** —— Web 工作空间与交互界面
- **Django** —— 后端 API 与业务服务
- **PostgreSQL、Redis、RabbitMQ** —— 数据、缓存与异步任务
- **Docker、Kubernetes** —— 本地开发与私有化部署

## 当前能力

项目支持富文本工作项、周期与燃尽图、模块化项目推进、可分享视图、AI 页面和实时数据分析。
