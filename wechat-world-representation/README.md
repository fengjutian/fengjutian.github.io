## 发布步骤

1. 用 Word 打开 `世界表征是什么-公众号版.docx`。
2. `Ctrl+A` 全选，`Ctrl+C` 复制。
3. 公众号后台新建图文，在正文区 `Ctrl+V` 粘贴，图片会自动上传。
4. 从头到尾检查一遍图片位置与公式显示。
5. 封面选 `images/00-cover-wechat.jpg`，标题填「世界表征（World Representation）是什么？」。
6. 建议摘要：世界表征是主体在内部构建的、关于外部世界的模型，是智能从感知走向理解、预测和行动的中间环节。

> 若个别图片没有自动上传，用 `images/` 里的同名文件在对应位置手动插入即可。

## 排版处理说明

- **正文、标题、列表、表格文字保持原文**；原文的「深入研究」一行也原样保留，排为小号灰字。
- **公式**：`P(S_{t+1:t+H} | M_t)` 渲染为 300dpi 图片；`M_t = { 位置, 速度, 方向, 道路, 障碍物 }` 用文字排版（斜体 *M* + 下标）。
- **表格**：两个表格使用 Word 原生表格，粘贴后一般仍可在公众号里编辑。
- **JSON 代码块**：等宽字体 + 浅灰底色 + 左侧蓝条，缩进原样保留。
- **配图顺序**与原文一致；原文有域名链接的图下保留小号灰字「参考：域名」，没有给出域名的两张图（红车特写、语义分割图）不加来源行。
- 图片宽度按清晰度做了区分：低分辨率图不强行拉满，信息图（世界模型示意图）则放大到整栏宽，保证文字可读。
- A4 预览页数较多是图片按清晰度优先排版所致，粘贴到公众号后为连续长文，不影响阅读。
