## 三步发布

1. 双击打开 `cognitive-game-wechat.html`（Chrome / Edge）。
2. 页面里 `Ctrl+A` 全选，`Ctrl+C` 复制。
3. 打开公众号后台 → 新建图文 → 正文区 `Ctrl+V` 粘贴。

编辑器会自动把 8 张图转存到公众号服务器。若某张失败，从 `img/` 里按图序手动拖入。

## 改文字 / 重出

```powershell
# 改完 article.txt 后
python .mockups\wechat\build.py     # 重新生成 HTML
node  .mockups\wechat\shot.js       # 截图核对（可选）
```

`build.py` 先按仓库根目录找图，找不到再找本目录，因此 `article.txt` 里的 `img/...` 直接可用。

## 与站内版的排版差异（同前）

- 无公式：公众号不支持 MathJax，全部改写成句子。
- 无外链：站外链接不可点，`doi:` 与 arXiv 只留在站内版。
- 四列宽表改竖排卡片：手机横滑读不了。
- 样式全内联：编辑器会剥掉 `<style>` 与 class。

## 注意

本目录位于 `.mockups/`，按仓库 `.gitignore` 不入库，是本地发布工具。若要长期保留公众号版，需要把它挪进版本控制（例如 skill 目录下），否则只能靠 `article.txt` 重建。
