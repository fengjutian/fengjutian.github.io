# 《智能的本质》微信公众号排版稿

按原文结构整理，正文一字未改；仅做了公众号发布必需的形式转换。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `智能的本质-公众号版.docx` | **发布用主文件**，图片、公式、表格已全部内嵌 |
| `智能的本质-公众号版.pdf` | 版式预览（A4 分页仅为预览，公众号里是连续长文） |
| `images/00-cover-wechat.jpg` | 公众号头图，已按 2.35:1 裁好（1440×612） |
| `images/01-cover.jpg` … `12-neumann.jpg` | 原文配图原文件，备用 |
| `content.py` / `build_docx.py` | 排版源文件，改文字后运行 `python build_docx.py` 可重新生成 |

## 发布步骤

1. 用 Word 打开 `智能的本质-公众号版.docx`。
2. `Ctrl+A` 全选，`Ctrl+C` 复制。
3. 公众号后台新建图文，在正文区域 `Ctrl+V` 粘贴。
4. 粘贴时公众号会自动上传 Word 内嵌图片；粘贴完成后从头到尾检查一遍图片是否都在。
5. 封面选择 `images/00-cover-wechat.jpg`，标题填「智能的本质：从世界表征、概率预测到未来生成」。
6. 建议摘要：主体通过感知构建世界表征，通过概率预测理解未来，再通过行动参与未来生成。

> 如果个别图片没有自动上传，用 `images/` 里的同名文件在对应位置手动插入即可。

## 排版处理说明

- **正文、标题、列表、表格文字均保持原文**，未增删、未改写。
- **公式**：公众号不支持 LaTeX，12 个独立公式已渲染为 300dpi 图片，行内符号保留为可编辑文字（斜体 + 上下标）。
- **表格**：4 个表格使用 Word 原生表格，粘贴后一般仍可在公众号里编辑。
- **原文外链**：公众号正文无法跳转外部链接，图下链接改为小号灰字「参考：域名」，共 11 处。
- **配图顺序**与原文一致：封面图 → 摘要 → 各章节插图 → 五位学者照片。
- A4 预览里图片较大、页数较多，是为了保证粘贴后图片清晰；公众号内为连续排版，不影响阅读。
